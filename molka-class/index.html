2콘티와 대사 만들기

챗GPT 콘티 = 컷마다 무엇이 보이고, 카메라가 어떻게 움직이고, 누가 무슨 말을 하는지 적은 영화 설계도.
컷 = 끊기지 않고 한 번에 찍은 장면 하나. 오늘은 10초짜리 컷 2개예요.
  1. 챗GPT에서 왼쪽 위 새 채팅
  2. 가운데 「ChatGPT에게 물어보세요」 칸에 프롬프트 붙여넣기 → Enter → 콘티 표가 나와요

- 서준: 24세 남성 대학생, 지은의 과 선배. 키 크고 잘생김. 다정하지만 말이 서툶

[조건]
- 컷 2개, 컷마다 10초, 가로 16:9 화면
- 젠지(Z세대) 느낌의 가볍고 귀여운 분위기
- 대사는 모두 한국어로. 한 사람이 한 컷에 1~2마디, 짧게
- 카메라는 컷마다 반드시 움직여야 해. 고정 화면(static)은 쓰지 마
- 카메라 무빙은 아래 그대로:
  컷 1: 0~5초 천천히 다가가기(Push In) → 5~10초 빠르게 좌우로 돌리기(Whip Pan)로 지은의 시선을 따라 주변을 훑기
  컷 2: 0~5초 어깨 너머(Over-the-Shoulder)에서 반원 돌기(Arc Shot) → 5~10초 천천히 멀어지기(Pull Out)
- 중학생도 이해할 수 있는 쉬운 말로

[이렇게 정리해 줘]

6영상 ① 만들기 (10초 · 의심)

구글 플로우 옴니(Omni) = 등록한 캐릭터의 얼굴과 목소리를 그대로 살려 영상을 만드는 구글의 AI 모델. 크레딧 = AI를 쓸 때마다 빠지는 포인트(무료 하루 50개).

  2. 노란 칸 [@캠퍼스] [@지은] [@서준]을 하나씩 지우고 → @ 입력 → 이름 입력 → Enter

🎬 영상 ① · 컷 1 의심
[@캠퍼스] 속 대학 캠퍼스 야외 벤치, 맑은 날 오후의 밝은 햇살.
[@지은](22세 여성)이 벤치에 혼자 앉아 책을 보고 있다. [@서준](24세 남성)이 다가와 로고 없는 흰색 종이 커피 컵(뚜껑 있는 따뜻한 음료)을 조심스럽게 내밀며 한국어로 다정하게 말한다: "이거… 너 좋아하는 거 맞지?"
지은은 안경 너머로 얼어붙은 채 컵을 보다가, 고개를 홱 돌려 주변 나무와 화분 뒤를 두리번거리며 한국어로 작게 말한다: "…지금 찍고 있는 거죠? 몰카 맞죠?"
카메라: 0~5초 두 사람이 함께 보이는 화면(medium two-shot)에서 천천히 다가가기(Push In) → 5~10초 빠르게 좌우로 돌리기(Whip Pan)로 지은의 시선을 따라 나무와 화분을 훑었다가 다시 지은의 놀란 얼굴로. 눈높이(eye level).
실사, 영화 같은 느낌, 얼굴과 옷은 [@지은], [@서준]과 똑같이.
모든 대사는 한국어. 영어로 말하지 않음.
음악 없음, 배경음악 없음, 자막 없음, 화면에 글자 없음.

⚠️ x1인지 꼭 확인! x2면 30크레딧이 한 번에 빠져요.
🎥 5~6초쯤 카메라가 휙 도는 동안 화면이 1초 정도 흐릿해질 수 있어요. 정상이에요(휩 팬). 너무 길게 흐리면 카메라 줄을 "5~10초 빠르게 좌우로 돌리기(Whip Pan)를 0.5초 안에 끝내고 지은의 놀란 얼굴로"로 바꿔 다시 생성하세요.

7영상 ② 만들기 (10초 · 진심)

구글 플로우

설정은 6번과 똑같아요. 프롬프트를 바꿔 넣고, 노란 칸을 @로 바꿔 주세요.

🎬 영상 ② · 컷 2 진심
[@캠퍼스] 속 같은 벤치, 맑은 날 오후의 밝은 햇살.
[@서준](24세 남성)이 [@지은](22세 여성) 옆에 앉아 로고 없는 흰색 종이 커피 컵을 건네고, 지은이 두 손으로 받아 쥔다. 컵은 영상이 끝날 때까지 지은의 손에 있다.
서준의 두 손은 비어 있다. 휴대폰, 카메라, 가방 등 어떤 물건도 들지 않는다.
[@지은]의 어깨 너머로 [@서준]의 얼굴이 보인다. 서준이 빈손을 펴 보이며 진지하게 한국어로 말한다: "아니야. 그냥… 너랑 친해지고 싶어서."
지은이 손가락으로 안경을 밀어 올리고, 손에 든 컵을 내려다보다 작게 웃으며 한국어로 말한다: "…일단 마셔 보고 생각할게요."
카메라: 0~5초 어깨 너머(Over-the-Shoulder)에서 천천히 반원 돌기(Arc Shot)로 지은의 얼굴 쪽으로 이동 → 5~10초 천천히 멀어지기(Pull Out)로 벤치에 나란히 앉은 두 사람이 함께 보이게. 눈높이(eye level), 밝은 자연광(natural daylight).
실사, 영화 같은 느낌, 얼굴과 옷은 [@지은], [@서준]과 똑같이.
모든 대사는 한국어. 영어로 말하지 않음.
음악 없음, 배경음악 없음, 자막 없음, 화면에 글자 없음.

⚠️ 영상에 휴대폰이 생기거나, 컵이 갑자기 손에 나타나면 그 영상은 버리고 다시 생성하세요. AI는 대사에 나온 단어("찍고", "마셔")로 물건을 멋대로 만들어요. 그래서 이 프롬프트에 "두 손은 비어 있다", "컵은 끝까지 지은의 손에"를 적어 둔 거예요.

9배경음 빼기 (배경음악이 들릴 때만)

BGM OFF 배경음 분리 = AI가 영상 속 소리를 대사·효과음과 배경음악으로 나눠 주는 것. 플로우가 몰래 깔아 둔 음악을 빼고 대사만 남겨요.

▲ BGM OFF 작업 화면 — 왼쪽에 영상을 넣고, 오른쪽에서 남길 소리를 골라요

먼저 영상 2개를 재생해 들어 보세요. 대사만 들리면 이 단계는 건너뛰어요. 대사 뒤에 음악이 깔려 있으면 아래처럼 빼 주세요.

  1. BGM OFF를 크롬으로 열기
  2. 「영상을 여기에 놓아주세요」 칸에 몰카_컷1 영상 끌어다 놓기
  3. 오른쪽 남길 소리 선택에서 배경음 중간 (추천) 그대로 두기
  4. 배경음악 분리하기 → 클릭 → 끝나면 들어 보고 영상 내려받기
  5. 컷2도 똑같이

⏳ 처음 한 번은 AI 프로그램을 내려받느라 몇 분 걸릴 수 있어요. 영상은 인터넷에 올라가지 않고 내 노트북 안에서만 처리돼요.

10배경음악 만들기

플로우 뮤직 연주곡(Instrumental) = 가사·목소리 없이 악기 소리만 있는 음악. 로파이(lo-fi) = 편안하고 살짝 빈티지한 느낌의 잔잔한 음악.
  1. 플로우 뮤직 → 로그인 → Google로 계속하기
  2. 가운데 「함께 만들어 봐요…」 칸에 아래 프롬프트 붙여넣기 → Enter

▲ 플로우 뮤직 첫 화면 — 가운데 칸에 프롬프트를 넣어요. 가사 칸은 따로 없어요.

  1. AI 프로듀서가 30초쯤 뒤 곡을 만들어 줘요 (곡은 1분이 넘게 나와요 — 캡컷에서 20초로 잘라요)
  2. 가사 확인: 곡 제목 클릭 → 아래 Lyrics에 [Instrumental]이라고 나오면 가사 없는 곡 ✅
  3. 곡의 ⋯ → Download → MP3 → 다운로드 폴더에 저장
🎵 배경음악 · 가사 없는 로파이
가사 없는 연주곡(Instrumental)만 만들어 줘.
가사 없음, 노래 없음, 보컬 없음, 허밍·코러스·말소리도 없음.
대학 캠퍼스 벤치에서 소심한 여학생과 다정한 선배가 처음 친해지는 20초짜리 짧은 영화의 배경음악.
가볍고 살짝 설레는 로파이(lo-fi) 곡. 부드러운 일렉트릭 피아노와 가벼운 드럼 비트, 템포 약 85 BPM.
처음은 조심스럽고 귀엽게, 중간부터 살짝 밝고 설레게, 부드럽게 끝나기.

11캡컷으로 편집하기

캡컷 PC 타임라인 = 화면 아래 영상·음악을 순서대로 놓는 긴 줄. 하드컷 = 효과 없이 영상을 바로 이어 붙이는 것(영화 대부분이 이렇게 해요). 페이드 아웃 = 소리나 화면이 서서히 작아지며 끝나는 것.

▲ 캡컷 첫 화면 — 맨 위 큰 「프로젝트 만들기」 버튼을 눌러 시작해요

  1. 캡컷 첫 화면 맨 위 + 프로젝트 만들기 클릭 → 편집 화면 맨 위 가운데 프로젝트 이름 클릭 → 이거 몰카죠 → Enter
  2. 가져오기 → 컴퓨터에서 → 왼쪽 다운로드 → 영상 2개(Ctrl 누르고 클릭, 9번을 했다면 배경음 뺀 영상)와 음악 선택 → 열기
  3. 컷1 → 컷2 순서로 아래 타임라인에 끌어놓기, 음악은 그 아래 줄 맨 앞에 붙이기
  4. 대사는 살려요! 영상 소리는 끄지 말고, 음악 클릭 → 오른쪽 볼륨을 -15dB 정도로 낮추기 (대사가 잘 들리게)
  5. 음악 자르기: 마우스를 영상이 끝나는 곳(20초)에 올려 주황색 선이 끝에 오게 → Ctrl+B → 뒤에 남은 음악 클릭 → Delete
  6. 남은 음악 클릭 → 오른쪽 페이드 아웃 칸에 2 입력
  7. 두 영상 사이에는 전환 효과를 넣지 않아요. 그냥 붙입니다(하드컷). 전환을 넣으면 두 영상이 겹쳐지면서 20초보다 짧아지고, 서 있던 사람이 앉은 채로 밀려 들어오는 게 더 티 나요.
  8. 컷2(마지막 영상) 클릭 → 오른쪽 기본 탭 → 페이드 아웃(영상) 0.7 입력 → 화면이 어둡게 끝나요
  9. 타임라인 맨 끝에 마우스를 올려 총 길이가 20초인지 확인 (10초 + 10초)

⏱️ 이 영상은 10초 + 10초 = 20초로 고정이에요. 중간에 흐릿한 부분이나 말 사이 공백이 거슬려도 영상을 자르지 마세요. 자르면 대사가 잘리고 20초가 깨져요. 마음에 안 드는 클립은 자르는 대신 그 클립만 다시 생성합니다(6·7번).
✂️ 캡컷은 마우스가 있는 곳(주황색 선)에서 잘라요. 엉뚱한 곳이 잘리면 Ctrl+Z로 되돌리기!
💎 보석·Pro 표시가 있는 효과는 유료라서 쓰지 마세요.

  2. 해상도 4K → 1080P, 코덱 HEVC → H.264, 형식 mp4, 프레임 속도 30fps 확인
